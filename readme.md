# Часть 3
Язык $L_{35}$ состоит из строк вида $w\overline{w}$, где $w \in \{0,1\}^*$, а $\overline{w}$ — строка, полученная из $w$ заменой $0$ на $1$ и наоборот.

Если язык $L$ регулярен, то существует такое число $p \ge 1$ (длина накачки), что для любого слова $s \in L$ с условием $|s| \ge p$ найдутся слова $x, y, z$, для которых выполняются следующие свойства:
1. $s = xyz$;
2. $|xy| \le p$;
3. $|y| \ge 1$;
4. для всех $i \ge 0$ слово $xy^iz \in L$.

Предположим, что язык $L_{35}$ является регулярным. Тогда для него существует длина накачки $p$.

Выберем слово   
$s = 0^p 1^p.$  
Это слово принадлежит $L_{35}$, так как его можно представить в виде $w\overline{w}$, где $w = 0^p$, а $\overline{w} = 1^p$. Длина слова $|s| = 2p \ge p$.

По лемме о разрастании слово $s$ можно разбить на три части:  
$s = xyz,$  
где $|xy| \le p$, $|y| \ge 1$, и для любого $i \ge 0$ слово $xy^iz \in L_{35}$.

Так как $|xy| \le p$, а первые $p$ символов слова $s$ — это нули, то и $x$, и $y$ состоят только из нулей. Следовательно,  
$y = 0^k, \quad k \ge 1.$

Рассмотрим слово, полученное при $i = 0$:  
$xz = 0^{p-k}1^p.$
Согласно лемме, это слово обязано принадлежать языку $L_{35}$.

Любое слово из $L_{35}$ имеет вид $w\overline{w}$. В таком слове количество нулей всегда равно количеству единиц.

Проверим слово $xz = 0^{p-k}1^p$:
*   Количество нулей: $p - k$
*   Количество единиц: $p$

Так как $k \ge 1$, получаем $p - k \ne p$. Следовательно, количество нулей не равно количеству единиц, а значит, $xz \notin L_{35}$.

Мы получили, что слово $xz$ должно принадлежать $L_{35}$, но оно не принадлежит ему. Это противоречие.

Следовательно, наше предположение о регулярности языка $L_{35}$ было неверным.

Итог:
$L_{35} = \{w\overline{w} \mid w \in \{0,1\}^*\}$
не является регулярным.
